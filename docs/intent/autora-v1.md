# Intent: Autora v1

- **Outcome:** iOS-приложение Autora — купить и продать легковое авто в РБ лучше, чем av.by (стабильность, поиск, editorial UI, BYN+USD справочно).
- **User:** частный покупатель и частный продавец в Беларуси.
- **Why now:** av.by ломает зум/сессию, прячет USD, лимитирует телефоны, сваливает сервисы в «Прочее».
- **Success:** TestFlight — поиск, карточка, чат/звонок, подача за 2–3 минуты, лента заполнена демо.
- **Constraint:** Firebase `serzhanovich-ecosystem-ce700`; префикс `autora`; не ломать сестёр; не парсить av.by; UI ru.
- **Out of scope:** грузовики/мото/запчасти, гараж, VIN-отчёт, журнал, услуги, веб, Submit в App Store, Algolia, paywall на телефон.
