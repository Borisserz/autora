# Review-Personas

Три прохода по реальному UI/коду. Связанные: [[Review-Critics]] [[Avby-Flows]] [[UI-Design]]

## A — Покупатель, Минск, VW Passat

**Что пробовал:** хаб → поле «Марка, модель» `passat` → фильтры. В сиде Passat есть (`lst-000`). Чип Volkswagen на хабе работает. В фильтрах марка/город/кузов — `TextField`, не список.

**Трение:** Минск и седан нужно вбить руками. Сравнить два Passat нельзя: `toggleCompare` пишет в массив и молчит.

**MUST:** пикеры марки/кузова/города из сида + экран сравнения до 3 лотов.

## B — Первый продавец, 2–3 минуты

**Что пробовал:** таб Объявления → войти (демо) → плюс → мастер. Шаги: фото → VIN → марка/модель/год → цена → город → описание.

**Трение:** шаг фото — заглушка. Публикация всегда с чужим Unsplash. Город свободным текстом. Без телефона в профиле — `AppError.needPhone` (у демо-профиля телефон есть).

**MUST:** `PhotosPicker` вместо «позже»; без фото — свои кадры или пусто, не чужой сток.

## C — Гость, закладки, потом вход

**Что пробовал:** сердце на карточке (без логина) → Избранное / Закладки. `UserDefaults` `autora.favorites`. Вход в Профиле не чистит закладки. Сохранить текущий фильтр нельзя — только сидовые «Passat до 20 000 Br».

**Трение:** гость копит фильтр на хабе и теряет его, если свернёт сессию. «Поиски» обещают сохранение с хаба, кнопки нет.

**MUST:** кнопка «Сохранить поиск» на хабе → вкладка Поиски.
