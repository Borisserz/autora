# Avby-Flows

Сверка слайсов Autora (не пиксели).

1. Хаб поиска: счётчик → марка → модель → поколение (чипы со счётчиками) → Показать N → лента. Autora: без запчастей/гаража/VIN-баннера.
2. Избранное: Закладки | Поиски.
3. Объявления: мои + плюс. Не копировать баг empty state «закладки».
4. Сообщения: логин для чата.
5. Пятый таб av.by = Прочее. Autora = Профиль.
6. Карточка: фото, бейджи ТОП/VIN (VIN — факт наличия, не отчёт), спека, цена, сердце.
7. Сайт-фильтр: марки со счётчиками, год, цена USD, объём.
